# @apilki/yandex-market — Postman Collection

**Запросов: 174 · Собрано: 2026-11-24**

Готовая [Postman Collection v2.1](postman/collection.json) для **Yandex Market Partner API**: 174 запроса — все операции официальной спецификации, по папкам-разделам.

Полнота проверяется при сборке: число запросов = число операций в спецификации,
иначе сборка падает. Коллекция перезаписывается пайплайном apilki при каждом
изменении API — руками не редактируется.

## Как импортировать

1. Скачайте [`postman/collection.json`](postman/collection.json).
2. Postman → **Import** → выберите файл.
3. Задайте `apiKey` в авторизации коллекции (тип **API Key**, ключ `Api-Key`, значение —
   ключ из кабинета Яндекс Маркета). Авторизация применена на всю коллекцию.
